## Changes made for this pack

- **CC-Checkerboard**: pressing a letter key in the menu no longer crashes it.
- **drmon (Draconic reactor)**: Patched for this pack: finds the input gate by type 'flux_gate' on DE 1.12 (the fork looked for 'flow_gate', which this DE version does not use), never picks the output gate as the input gate, and uses the original safer defaults (target field 50%, emergency stop below 15%), and reports a missing monitor clearly.
- **All programs**: run from /rom; programs that save data are copied to /extra/<name> on first run.
