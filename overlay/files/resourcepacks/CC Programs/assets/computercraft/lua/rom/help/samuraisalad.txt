Samurai Salad

Slice flying fruit with the mouse, Fruit Ninja style.

Usage: samuraisalad

Needs: advanced computer (colour)

This program saves data, so the first run copies it (121 KB) to /extra/samuraisalad. Delete that folder to reset it.
