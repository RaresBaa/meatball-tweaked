Pumpkin Carver

Carve a 3D pumpkin with the mouse. Ctrl opens the menu.

Usage: pumpkincarver

Needs: advanced computer (colour)

This program saves data, so the first run copies it (113 KB) to /extra/pumpkincarver. Delete that folder to reset it.
